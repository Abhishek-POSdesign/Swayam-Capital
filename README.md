**Swayam** is Abhishek Sikka's custom, rule-enforced trading platform.

- **Architecture:** 6 Core Components (Daily Readiness, Market Context, Setup Queue, Active Trades, Journal, Backtester + Visual Strategy Builder)
- **Broker & Market Data:** FYERS API v3
- **Math Engine:** Black-Scholes-Merton Greek calculation via `py_vollib_vectorized`
- **Execution Mode:** Paper-trading (Phase 1) & Live FYERS Execution (Phase 2)
