# Web Frontend (Swayam Capital)

This directory will contain the lightweight web frontend for the Swayam Capital dashboard and the visual Options Strategy Builder.

- **Technology Stack:** Vite + Plain Modern JavaScript / HTML + Plotly.js (`plotly.js-dist-min`).
- **Charting Constraint:** Only the interactive Options Strategy Builder payoff curve is rendered internally. All other charting relies on external TradingView windows surfaced via `tradingview_helper.py`.
- **Status:** Scaffolding and full implementation will take place in **BUILD-3** following the R2 scoping specification.
